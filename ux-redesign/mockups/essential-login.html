If something goes wrong - these are the secured variations

Wrong credentials - deliberately vague (no account enumeration)

⚠ Wrong email or password Check both and try again, or reset your password. The message never reveals whether the email exists.

Too many attempts - brute-force lockout (HTTP 423)

🔒 Too many attempts For your safety, sign-in is paused. Try again in 5 minutes.

Wrong 2FA code · recovery codes running low

⚠ That code didn't match Codes refresh every 30 seconds - enter the newest one.

2 recovery codes left  Generate more in Profile → Security before you run out.

Submitting - pending state (Doherty < 400ms)
