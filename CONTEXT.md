# Opzava ubiquitous language (canonical glossary)

Use these terms EXACTLY. If a doc, issue, or conversation uses a term differently, this file wins;
if a new term crystallises, add it here in the same slice. Definitions only — design detail lives in
`ARCHITECTURE.md`, current PRDs/ADRs, and their current foundation decision ledgers.

`1db502d722ca33285148251a7660695868ad6a30`. The parent map and migration manifest designate it
current planning input until #237 consumes and freezes it; this status does not claim
implementation.

| **Harness Supervisor**                     | The Runner-owned local module that durably reserves worktrees/resources, invokes a Harness Adapter from a typed plan, supervises process descendants, checkpoints, contains, and reconciles under the Lease Enforcer.                                                                                                                                                                                                                                                                                                                               | A Harness Adapter, workflow authority, or the independent Lease Enforcer.                                                                                                                                          |

| **Lease Enforcer**                         | The independently OS-supervised local component that verifies signed lease/fence authority, maintains the conservative monotonic deadline, and stops or quarantines the exact supervised resources when authority is invalid or lost.                                                                                                                                                                                                                                                                                                               | The Runner daemon, a heartbeat, an unsigned timer, or proof that the DevTicket changed lane.                                                                                                                       |
| **Lease Secret Broker**                    | The isolated local/cloud component that redeems an exact lease-bound named-secret grant and performs only capability-bound typed operations without returning the raw secret to the Harness process tree.                                                                                                                                                                                                                                                                                                                                           | The secret vault, a generic proxy, an environment-variable injector, or permission for arbitrary credential use.                                                                                                   |
| **Server Command Trust Bundle**            | The versioned Runner-pinned public-key chain that assigns distinct server signing keys to Registry ceremony, connection acceptance, time-anchor, semantic-order, delivery-envelope, fact-admission, and connection-control purposes with activation, retirement, and revocation bounds. | **Runner Command Delivery**                | One durable, at-least-once delivery of an already-authorized typed Runner order, bound to exact Runner Registry or Execution authority and an immutable semantic digest; its transport acknowledgement proves receipt of bytes only.                                                                                                                                                                                                                                                                                                                | A DevTicket command decision, proof of process action, a shell command, or a Runner Receipt.                                                                                                                       |
| **Runner Receipt**                         | A signed, ordered, typed Runner observation admitted only when its enrollment/connection, delivery, lease, fence, nonce, contract, repository/worktree/process, sequence, and policy bindings match current server authority. The closed exception is an independently Lease-Enforcer-signed authority-reducing containment fact under the last accepted Enforcer authority after connection/key loss.                                                                                                                                              | A transport acknowledgement, heartbeat, vendor event, lane transition, self-asserted approval, or authority to start/renew/resume through the Enforcer exception.                                                  |
| **Runner Checkpoint**                      | A signed Runner observation of the last confirmed repository, worktree, process, grant, container/port, and safe continuation state for one exact lease/fence.                                                                                                                                                                                                                                                                                                                                                                                      | Proof that containment completed, authority to resume, or a replacement Ready/Review evidence package.                                                                                                             |
| **Reconciliation Observation**             | The signed reconnect inventory of journal cursors, old process/worktree/grant state, and containment dispositions that is recorded before any continuation decision.                                                                                                                                                                                                                                                                                                                                                                                | Resurrection of an old lease, automatic cloud failover, or proof that unknown execution is safe.                                                                                                                   |
| **OpenClaw Node**                          | An OpenClaw-native capability-bearing companion runtime endpoint.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   | A paired Device; a Dev Board Runner, even when one physical machine hosts both.                                                                                                                                    |
| **OpenClaw Device**                        | An OpenClaw-native paired client identity with its own role/token record.                                                                                                                                                                                                                                                                                                                                                                                                                                                                           | A Node; a Dev Board Runner, even when one physical machine holds both identities.                                                                                                                                  |

| **Ready Approval**                         | The authoritative human approval bound to one exact Ready Contract Version, dependency set, policy/risk evaluation, Human Owner, and required-input state.                                                                                                                                                                                                                                                                                                                                                                                          | A permanent approval, a validation artifact, or a Needs Human Approval Request.                                                                                                                                    |

| **Blocked Episode**                        | The required reasoned record for one DevTicket in Blocked, including prior lane, condition, checkpoint, containment, notification, and a truthful closure: resolved with proof or superseded with unresolved refs preserved.                                                                                                                                                                                                                                                                                                                        | A dependency lock, free-form status string, or false claim that an obsolete condition resolved.                                                                                                                    |

## Legacy route note

The currently implemented `/tasks` and `/issues` routes, their existing Task aggregate/projection,
and their MCP/issue-adapter behavior remain **legacy as-built code until the migration is
completed**. They describe current runtime reality, not the target product vocabulary. New product
design and replacement implementation follow PRD-019, ADR-017, the Dev Board decision ledger, and
the migration manifest; do not use Q17 to extend the legacy model.
