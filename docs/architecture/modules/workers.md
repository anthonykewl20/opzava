## Overview
Its load-bearing invariants are the ADR-003 two-token model, where the broker hot path uses `operator.write` plus `operator.approvals` while provisioning uses separate short-lived JIT `operator.admin`, and ADR-015's rule that only `worker-provisioning` reaches the Docker mutation socket proxy `docs/adr/ADR-003-gateway-broker-acl-two-token.md:57` `docs/adr/ADR-003-gateway-broker-acl-two-token.md:61` `docs/adr/ADR-015-deployment-parity.md:62` `docs/adr/ADR-015-deployment-parity.md:64`.

## Cross-cutting notes
- The admin/JIT two-token split is hard-coded in Ask Admin constants and backed by ADR-003: broker hot path gets `operator.write` plus `operator.approvals`, while worker provisioning uses separate short-lived `operator.admin` `apps/workers/src/provisioning/ask-admin-agent.ts:21` `docs/adr/ADR-003-gateway-broker-acl-two-token.md:57` `docs/adr/ADR-003-gateway-broker-acl-two-token.md:61`.
- The docker-socket-proxy is the only Docker mutation surface, and ADR-015 says only `worker-provisioning` can reach it while `gateway-broker` must never mount Docker or provision containers on the hot path `docs/adr/ADR-015-deployment-parity.md:62` `docs/adr/ADR-015-deployment-parity.md:64`.
- Port misplacement is real: `OpenClawAdminRpcPort` is defined inside `apps/workers/src/provisioning/openclaw-admin-client.ts`, and `GatewayRuntimePort` is defined inside `apps/workers/src/provisioning/gateway-admin-connections.ts` beside its Docker adapter `apps/workers/src/provisioning/openclaw-admin-client.ts:21` `apps/workers/src/provisioning/gateway-admin-connections.ts:116` `apps/workers/src/provisioning/gateway-admin-connections.ts:2103`.
- `ConnectionsProvisioningPort` is a real seam because it has 4 adapters total and two workers adapters, while `GatewayRuntimePort` is hypothetical today because it has only one Docker adapter even though ADR-002 keeps K8s and Nomad as later adapters `packages/ports/src/connections-provisioning.ts:239` `apps/workers/src/provisioning/gateway-admin-connections.ts:2741` `apps/workers/src/provisioning/gateway-admin-connections.ts:4485` `docs/adr/ADR-002-tenancy-provisioning.md:53`.
