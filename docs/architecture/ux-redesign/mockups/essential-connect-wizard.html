Step 3 — Copy the command

Link Claude Code

✓ ✓ 3 Copy command 4

Paste this in your terminal. It adds Opzava to Claude Code and points it at your workspace — your API key is filled in from Settings.

$claude mcp add opzava \
--env MC_URL=https://ops.acme.dev \
--env MC_API_KEY=sk-opz-••••••••2f9c \
-- node /opt/opzava/scripts/mc-mcp-server.cjs

🔑 MC_API_KEY is pulled from your Settings — paste a new key if you don't have one yet.
