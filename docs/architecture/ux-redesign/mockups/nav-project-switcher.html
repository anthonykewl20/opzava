What changed & why

  • Switcher promoted from profile popover to the rail. The previous ContextSwitcher/OrgRow was buried inside the avatar menu alongside logout and org provisioning — Fitts's Law violation + discoverability failure. Now it is a persistent, always-visible PROJECTS section between CORE and OBSERVE (Slack/Linear channel-list pattern).
  • Projects added to ⌘K as top-ranked jumps. QUICK_NAV_COMMANDS previously had no project branch and /api/search had no project SQL path. Projects now seed the empty palette above panel commands (needs ~12-line SQL branch). A project jump sets activeProject then navigates to that project's Tasks view.
  • 3-signal active state. Active project (Q2 Content Push) shows: 3px --accent left border + --accent-soft bg + font-medium weight. One-accent rule: color dot is decorative identity only, not a status signal.
  • Attention dot. Ships as task-count + overdue only (derivable from tasks.project_id). Approval/blocked dot is gated behind adding project_id to opzava_approvals/workflow_runs — schema migration required. (R-T4.3)
  • fetchProjects unblocked for all roles. Current code gates the project list on isAdmin. /api/projects GET already allows viewer — this is a pure UI regression. Removing the gate is required before any of the above works for the Essential/normal-user audience. (R-T4.4)
