Opzava — the overall UI/UX

Interactive HTML proofs of the proposed redesign, organised as the two experiences a person actually lives in. Pick the audience and walk the whole thing — each world has one consistent navigation and never bleeds into the other. Audience model in 07; the three conversational surfaces (orchestrator / per-project assistant / human messages) in 09. Every screen holds the 15 px floor, one accent, WCAG AA, and explicit loading / empty / error states.

Essential — the everyday experience

calm · light · jargon-free

What a normal, non-technical user sees. One calm top bar on every page — never the dark sidebar: ◆ Opzava · Home · My stuff · Messages ③ · Activity ② · ✦ Ask Opzava · Find… A calm adaptation of Basecamp, with a per-project AI assistant, a human Team room, a Slack-style Messages hub for all your chats, and one cross-project Ask Opzava. Activity is where every @mention and call-out — from every project — collects, so a tag is never missed. Quick project switching is the ▾ beside a project title (plus Find…) — no permanent sidebar, keeping it Basecamp-calm. Full / admin view is reserved for admins — everyday users stay here in Essential. Walk it in order:

1Home · Your projects

The Lineup — every project as a calm card, a cross-project “needs you” rollup, and an Ask Opzava entry. Warm, content-first.

2A project workspace

Tool tiles — To-dos, Board, ✦ Ask your assistant, Team, Docs, Schedule, Updates. The project title has a ▾ to quick-switch projects.

3Ask your assistant

The per-project AI chat — inline steps, artifact and approval cards, with a back-link up to Ask Opzava.

4Team room

The per-project human room (Campfire-lite) — one calm thread, the sibling of the Assistant tab. People, not AI.

5Messages · Slack-style

All your team chats in one calm place — project rooms + direct messages on the left, the open conversation on the right. The Slack feel, kept calm. Humans only.

6Ask Opzava

The cross-project AI in the calm view — opens on a status digest across every project and acts inline. Same nav, no dark sidebar.

7To-dos

Checklists with a progress bar — each item shows the AI on it (✦), a live status (Working… / Draft ready · review), comment counts, and due date. Glanceable like the Board cards.

8Board · swim lanes

Triage → In progress → Done. Rich cards (ID, label, steps bar, due, ✦ AI, status, 💬/📎). A board switcher (“Customer Support ▾”) jumps between projects’ boards.

9Boards · all projects

A PM’s cross-project board summary — every project’s lanes (Triage / In progress / On hold / Done) as a stacked bar, what needs you, severity-sorted. “Open board →” to dive in.

10Discovery

Shape a new feature/product with Atlas — a calm idea board (New → Exploring → Decided, Parked tucked away), a quiet 👍 to converge, AI on demand via ✦ Ask Atlas, then Connect to a project. Calmed by an MMX-vision + UX-law + creativity-psychology consensus (see 10 §8). Project tab after Updates.

11An idea, opened

A Discovery idea opened — the research detail (no quality-review / task machinery): the idea, votes, a flat build-on discussion, research sources, and an ✦ AI consensus panel where several assistants weigh in. Multiple people + multiple AIs; converge → Connect to a project.

12A card, opened

Steps, assignee, due date, evidence/files, a quality-review approval, and a human↔AI comment thread.

13My stuff

Everything across projects that needs you or that you’re following — adapted for human-in-the-loop.

14Activity · your inbox

Every @mention and call-out from every project, plus AI hand-offs and approvals — one cross-project inbox so a tag is never missed. Source by glyph, never colour.

15Blank slates & states

Empty + error states as first-class screens, in plain words — no error codes for everyday users.

Marketing & Promotion — a focused project type

Essential · marketing-native tiles

A project type tuned for one job: run a campaign end to end. Same calm Essential top bar, but the generic tiles are swapped for marketing-native ones along the lifecycle Plan → Create → Approve → Publish → Measure. Researched and decided in 11 — The “Marketing & Promotion” project type; reach it from Home → Q3 Launch Campaign, or pick it when you start a new project. Calm first, no KPI wall — status is a label, never a hue.

Start a new project · the type picker

Where a project type is chosen — Blank or Marketing & Promotion, each previewing its tile lineup (Sales / Support / Events follow the same pattern). The ＋ New project button opens this everywhere. Choosing Marketing swaps the generic tiles for the campaign-native set.

Workspace · the campaign home

Seven marketing-native tiles — Campaigns · Content Calendar · Approvals · Assets · Performance plus ✦ Ask your assistant and Team — with a Latest-activity strip. The calm Basecamp grid in marketing vocabulary.

▣ Campaigns · the spine

Every campaign and the stage it’s in — Plan → Create → Approve → Publish → Measure. Channel tags, the ✦ AI drafting inline, comment/asset counts. The Card Table, marketing-fitted.

📅 Content Calendar · what goes out when

A month grid across every channel, Channel/Campaign filters, and a “Coming up · 7 days” rail. Status by glyph + label (✓ published · ● scheduled · ○ draft), never colour.

✓◷ Approvals · the bottleneck queue

Everything waiting on a sign-off, grouped Needs review · Changes requested · Approved, oldest first. One-click Approve / Request changes — a calm age, never a red alert.

📎 Assets · the creative shelf

Every approved file and draft in one place — tagged by campaign and type, each with a neutral ✓ Approved / ◷ In review status. A calm shelf, not a DAM.

📈 Performance · the calm loop-closer

Goal vs. actual for live campaigns — one number that matters each, a single-accent progress bar, a trend glyph, and a “needs attention” label. No charts, no KPI wall.

🎯 Ads Report · paid, analysed

Spend and return by channel (Meta · Google · LinkedIn) with an ✦ Atlas analysis — what the numbers say plus a recommendation. Calm numbers + table, no chart wall. One of the Reports & analysis set.

📧 Email Report · sends, analysed

Opens, clicks, and conversions per send, with an ✦ Atlas analysis reading subject-line and timing wins into a recommendation. Same calm report shell.

📝 Blog Report · content, analysed

Traffic, engagement, and signups per post, with an ✦ Atlas analysis on what content to write next. The third of the channel reports.

Your tools — linked-tool health & the connect wizard

Essential · calm health, no traffic light

A calm health surface for the terminal & desktop agent tools linked to your account — Claude Code, OpenCode, Codex CLI, Codex Desktop, Claude Desktop, OpenClaw, Hermes. Status is a glyph + label, never colour (✦ Active · ● Connected · ◐ Degraded · ○ Disconnected · ＋ Not linked); the one accent marks only what needs you. The glance lives on Home and in the avatar menu — not a topbar pill (chrome stays navigation-only). If nothing's linked yet, a modern 4-step wizard does the connecting. Researched and decided in 12 — Linked Tools Health & the Connect Wizard.

🔗 Your tools · the health surface

The seven linked tools across all five states — de-coloured rows with a glyph+label status badge, stale-only last-seen, inline Reconnect/Connect, and an admin re-link command behind Technical details. The one accent is the single tool that needs you.

🔌 Nothing linked yet · the empty state

The most important screen — a calm “Connect your first tool” hero with one primary CTA and a dimmed ghost-preview of what linked tools will look like. Jargon-free, outcome-framed.

＋ The connect wizard · four steps

Pick a tool → choose a method → copy one command (a modern copy-block with the key pre-filled) → live-verify (✦ waiting → ✓ Connected). Honest: live/gateway auto-poll, MCP asks you to confirm — it never fakes a handshake.

Principles applied

Two worlds, one nav eachEssential is calm top-nav end-to-end; Full is the dark sidebar end-to-end. No screen mixes them and no link crosses over — you always know which world you’re in. 07 / 09.
Three conversations, never confusedCross-project Ask Opzava (AI) · per-project Ask your assistant (AI) · human Messages/Team — different homes; AI vs human is glyph + label (✦ / initials), never colour. 09.
Essential = BasecampProjects as calm workspaces, To-dos, a Board, plain copy, generous whitespace — proven patterns (Jakob’s Law), not novelty. 08.
15px text floorBody never below 15px (WCAG 1.4.4); 13px only for tertiary metadata; the old 10px token is retired.
One accentA single saturated hue per view (cyan in Full, indigo in Essential); semantics desaturated; one primary action per region.
≤9 destinations + disclosureHick / Miller / Tesler — collapse the 32-item nav; progressive disclosure; advanced behind accordions.
All four async statesLoading (skeleton) · Loaded · Empty (with a next action) · Error (role="alert" + retry). No silent dead-ends.
